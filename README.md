# Замыкание контуров DXF

Инструмент для подготовки DXF к резке. Находит места, где контур не сомкнут,
сшивает висячие концы в пределах заданного радиуса и собирает разрозненные
отрезки в замкнутые полилиниии. Результат сразу видно в окне, зум — колесом мыши.

![иконка](dxf_close/assets/icon_256.png)

## Установка

**Windows** — PowerShell, одна команда (Python поставится сам, если его нет):

```powershell
powershell -c "irm https://raw.githubusercontent.com/SKLFIR/dxf-close/main/install.ps1 | iex"
```

**macOS / Linux** — терминал:

```bash
curl -fsSL https://raw.githubusercontent.com/SKLFIR/dxf-close/main/install.sh | bash
```

В обоих случаях на рабочем столе появится ярлык **«Замыкание контуров DXF»**.
Повторный запуск команды обновляет программу до свежей версии.

## Как пользоваться

Двойной клик по ярлыку → выбрать DXF. Дальше:

- **Радиус сшивки, мм** — на каком расстоянии считать два конца одним стыком.
  Начните с 0.1; если остались открытые контуры, увеличивайте. Кнопки `−` / `+`
  меняют радиус шагом 0.05, `Enter` — пересчёт.
- **К проблеме →** — по нажатию перелетает к очередному незакрытому месту.
- **Сохранить DXF…** — записывает результат рядом с исходником,
  файл `<имя>_замкнутый.dxf`. Оригинал не изменяется.

Цвета на экране:

| цвет | что это |
|------|---------|
| синий | замкнутый контур — всё в порядке |
| красная линия | контур остался открытым |
| красный кружок | висячий конец: радиуса не хватило |
| оранжевый | мостик, добавленный при сшивке |
| бледно-серый | штриховка — в сшивке не участвует |

## Штриховка

Штриховку нельзя обрабатывать вместе с контуром: это несвязанные штрихи, и
попытка их замкнуть превращает файл в кашу. На реальном знаке 5127 штрихов
узора ANSI37 давали 9612 ложных мостиков и 4519 испорченных контуров.

Поэтому порядок такой: **сначала собираются и замыкаются контуры, потом
отдельно добавляется штриховка — уже в виде обычных линий.**

- `HATCH` раскладывается в линии узора автоматически. Станок сущность `HATCH`
  всё равно не понимает, а ручное расчленение в CAD даёт ровно то же самое:
  на проверочном файле 5156 линий против 5127 при расчленении вручную, разница
  суммарной длины 0.03 %. Сплошная заливка узора не имеет — от неё остаётся очертание пятна.
- Уже расчленённая штриховка распознаётся по слою: у штриха оба конца висят
  сами по себе, у контура таких почти нет. На проверочном файле слой со
  штриховкой дал 100 % таких отрезков, слой с контуром — 0 %.

Строка **«Штриховка на слоях»** в окне показывает каждый слой с долей
отрезков, висящих сами по себе, и галочкой. Автоопределение можно переопределить
вручную — снять галочку, чтобы слой замыкался как контур, или поставить, чтобы
его оставили как есть. Галочка **«штриховку в результат»** решает, попадёт ли
она в выходной файл вообще.

## Что программа делает с геометрией

1. Читает всю геометрию модели: отрезки, полилинии, дуги, окружности, эллипсы,
   сплайны, содержимое блоков. Кривые спрямляются с точностью 0.01 мм.
2. Находит висячие концы — точки, где сходится ровно один отрезок.
3. Сшивает их: сначала попарно (концы навстречу друг другу), затем оставшиеся
   привязывает к телу ближайшего отрезка, разрезая его в точке привязки —
   это ловит случай, когда линия не дотянулась до середины другой линии.
4. Обходит получившийся граф и собирает полилинии. На развилках выбирает
   продолжение с наименьшим изломом.
5. Сливает точки, лежащие на одной прямой, с допуском 0.001 мм — файл заметно
   легче, форма не меняется.

Радиус применяется **только к висячим концам**. Это принципиально: если сшивать
всю геометрию подряд, крупный радиус схлопывает короткие отрезки — острия букв,
кончики веток — и рвёт контур там, где он был целым.

## Командная строка

Окно нужно не всегда — для пакетной обработки есть флаги:

```bash
dxf-close файл.dxf --check              # только отчёт, ничего не пишет
dxf-close файл.dxf -r 0.2 --save        # сшить радиусом 0.2 мм и сохранить
dxf-close файл.dxf -r 0.2 --save -o out.dxf
dxf-close файл.dxf --hatch-layer Стандарт --save   # слой считать штриховкой
dxf-close файл.dxf --no-hatch --save    # выбросить штриховку, оставить контуры
dxf-close --install-shortcut            # пересоздать ярлык на рабочем столе
```

На Windows исполняемый файл лежит в
`%LOCALAPPDATA%\dxf-close\venv\Scripts\dxf-close.exe`,
на macOS — в `~/Library/Application Support/dxf-close/venv/bin/dxf-close`.

## Отчёт

```
слой ЗНАК_СТЕНКА_1        отрезков  10580, сам по себе   0.0%
слой Стандарт             отрезков   5127, сам по себе 100.0%  → штриховка
отрезков: 10596  (мостиков добавлено: 16)
висячих концов: было 32 → осталось 0
контуров: 63 — замкнутых 63, открытых 0
вершин: 10596 → 10309
длина реза по контурам: 9980.80 мм
штриховка: 5127 линий (85216.97 мм)
```

Если «висячих концов: осталось» больше нуля — радиуса не хватило, увеличьте его.
Если остаются при любом разумном радиусе, посмотрите на эти места кнопкой
«К проблеме →»: обычно это не разрыв, а ветвление контура или наложенные линии.

python3 -m venv .venv && . .venv/bin/activate
